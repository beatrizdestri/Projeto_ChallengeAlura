# Conversor de Moedas 💱

## Descrição
O Conversor de Moedas é uma aplicação que permite converter valores entre diferentes moedas utilizando taxas de câmbio atualizadas. 
Ele é ideal para viajantes, investidores ou qualquer pessoa que precise realizar cálculos de conversão rapidamente.

## Funcionalidades
- Conversão entre diversas moedas (USD, EUR, BRL, etc.).
- Atualização em tempo real das taxas de câmbio através de uma API confiável.
- Interface amigável e responsiva (ou CLI, caso seja linha de comando).
- Histórico de conversões realizadas (se aplicável).

- Linguagem JAVA
